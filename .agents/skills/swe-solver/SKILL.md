# OpenHands Problem Solving Workflow

При решении сложных ошибок в коде строго следуй 4 фазам:
1. **Воспроизведение (Reproduction):** Не трогай рабочий код сразу. Сначала найди минимальный сценарий воспроизведения или напиши тестовый вызов/скрипт, подтверждающий баг.
2. **Локализация (Trace):** Найди точную строчку причины по стек-трейсу, а не пытайся переписать всю функцию наугад.
3. **Минимальный патч (Minimal Diff):** Вноси только те изменения, которые напрямую решают проблему. Не трогай соседнюю работающую логику.
4. **Верификация (Verification):** Запусти проект или тест (`npm run build` / `pytest`) и подтверди отсутствие побочных эффектов.
